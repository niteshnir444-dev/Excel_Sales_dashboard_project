# Excel Sales Dashboard Project

## 📊 Executive Summary & Profitability Dashboard

This project showcases an interactive **Sales Dashboard built using Microsoft Excel** to analyze business performance, profitability, and sales trends. It provides key insights into revenue, gross profit, cost of goods sold (COGS), units sold, and order volume through dynamic visualizations and interactive filters.

### Key Features
- **KPI Summary:** Total Revenue, Total Gross Profit, Gross Profit Margin, Total Units Sold, Total Orders, and COGS.
- **Monthly Sales Analysis:** Track monthly revenue and gross profit trends.
- **Country-wise Revenue:** Compare sales performance across countries.
- **Revenue by Channel:** Analyze revenue contributions from Corporate, Marketplace, Online Store, and Retail Partners.
- **Regional Comparison:** Compare sales performance across Central, Northern, Southern, and Western Europe.
- **Geographical Analysis:** Visualize country-wise sales performance using a map chart.
- **Interactive Slicers:** Filter the dashboard by product category, country, region, and quarter.

### Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Data Analysis and Visualization

### Project Objective
The objective of this project is to transform sales data into meaningful business insights, identify revenue and profit trends, compare regional and country-level performance, and support data-driven decision-making.

### Key Takeaway
This project demonstrates practical skills in Excel-based data analysis, KPI reporting, business intelligence, and interactive dashboard development.
